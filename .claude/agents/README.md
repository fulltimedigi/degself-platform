# وكلاء دق سلف (Claude Code subagents)

٦ وكلاء متخصّصون قابلون للتشغيل داخل الريبو. كل وكيل **للقراءة/التحليل فقط** — لا يكتب في الإنتاج، لا يرسل واتساب، ولا يعدّل ملفات. مبدأ «بشر في الحلقة» مضمون بتقييد الأدوات.

## كيف تشغّلهم
داخل جلسة Claude Code، نادِ الوكيل بالاسم واعطه المدخلات، مثلاً:
- «استخدم وكيل `garage-finder` لتقييم هذه القائمة مقابل الـICP: …»
- «شغّل `review-mining` على هذه التقييمات: …»

أو عبر أداة Agent مباشرةً بتحديد `subagent_type` باسم الوكيل.

## الوكلاء
| الوكيل | الدور | يخدم |
|---|---|---|
| `garage-finder` | اصطياد كراجات مرشّحة للانضمام + تقييم الملاءمة | التوسّع |
| `garage-qualifier` | تصنيف تخصّص/جودة كراج واحد (JSON) | جودة البيانات |
| `garage-outreach` | تسلسل واتساب عربي لإقناع كراج بالانضمام | التوسّع |
| `competitor-analysis` | مقارنة دق سلف بمنافسين على أبعاد محدّدة | الاستراتيجية |
| `review-mining` | استخراج أنماط/مشاعر من التقييمات | الثقة/الجودة |
| `cro-funnel` | تحليل قمع degself.com واقتراح تحسينات | النمو |

## المنظومة
```
التوسّع:      garage-finder → garage-qualifier → garage-outreach → انضمام
الجودة/الثقة: review-mining → إشارات ثقة  ·  garage-qualifier → تصحيح البيانات
النمو:        cro-funnel + competitor-analysis → قرارات المنتج/التسويق
```

## حدود مقصودة
- كل الوكلاء أدواتهم للقراءة فقط (Read/Grep/WebSearch/WebFetch) — لا Write/Edit/Bash ولا كتابة في قاعدة البيانات.
- `garage-outreach` يصيغ نصًّا فقط ولا يرسل، ولا يُفعّل أتمتة واتساب.
- `review-mining` يحلّل الموجود فقط — لا يولّد تقييمات (متوافق Google/FTC).
- نقاط المراجعة البشرية موثّقة داخل كل وكيل.

> الأصل: مكيّف من *"50 AI Agents for B2B Companies" — Klaym AI*، بإعادة بناء بالقالب فقط ومحتوى خاص بدق سلف. النسخة الكاملة للدليل في `docs/ai-agents-playbook.md`.
